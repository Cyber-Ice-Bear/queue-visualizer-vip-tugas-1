# Queue Visualizer

Interactive Queue Data Structure Visualization built using React, Tailwind CSS, and Framer Motion.

## Features
- Enqueue & Dequeue operations
- Real-time visualization
- Activity log
- Queue capacity
- Toast notifications
- Smooth animations
- Responsive design

## Technologies
- React
- Vite
- Tailwind CSS
- Framer Motion
- React Hot Toast

## Installation

```bash
npm install
npm run dev
```
